# こんなときどうする？「けむしを見つけたら？」— ストーリー案（改訂版）

対象：幼児〜小学校低学年 ／ 横型 1920×1080 ／ 3〜4分 ／ AIナレーション＋BGM＋効果音

## 方針（ユーザー指示）
- 今回は **毛のある虫（毛虫）だけ**。毛のないイモムシ（アオムシ・アゲハの幼虫など）は別の回にとっておく
- 子どもに「さわっていい虫」は教えない。**安易にさわらせない**
- 子どもがやることは **「さわらない」「大人に言う」** だけ
- **毛は風で飛ぶので、近づかない** ことも必ず伝える
- 主人公は前回の動画と同じ女の子（黒髪ボブ・白いセーター・緑のスカート・3Dの絵本風）
- 採用：**A案**（おさんぽ）。案内役テンちゃんはやめて、前回の女の子が主人公

## 伝えたいこと（1つだけ）
**「けむしを見つけたら、ちかづかない・さわらない。おとなに言う」**

### 内容のもと（事実）
- 毒のある毛虫の代表：**チャドクガ**（ツバキ・サザンカの葉。毛が風で飛ぶ／ぬけがらにも毒）、**イラガ**（カキ・サクラ・ウメの葉の裏。黄緑でトゲトゲ。さされると電気が走るように痛い）
- 見た目だけで毒のある・なしは子どもには分からない → 毛虫は全部「さわらない」
- もしさわっちゃったら：**こすらない・かかないで、すぐおとなに言う**（その先の手当ては大人がやる）

## A（おすすめ）「テンちゃんとおさんぽたんけん」
理由：同じ年ごろの子が公園で出会う場面そのままなので、いちばん覚えやすい。

- 仕掛け：案内役のテントウムシ「テンちゃん」と子どもたちが公園をおさんぽ。毛虫を見つけるたびに「どうする？」→「さわらない！おとなに言う！」をくり返して体で覚える
- 形：1つの公園を横スクロールで進む
- 最初の2秒：葉っぱのアップ → もぞもぞ動く毛虫 → 「あっ！けむしだ！」
- 流れ：オープニング → ツバキの葉でチャドクガ発見 →「毛は風でとんでくるよ」（小さな毛がふわっと舞う演出）→ 一歩さがる・近づかない→ 木の葉のうらでイラガ発見（トゲトゲ！）→ ベンチや地面を歩く毛虫（ここにもいるよ）→「もしさわっちゃったら？」（こすらない・すぐおとなに言う）→ 合言葉 → エンディング
- 見た目：やわらかい絵本風。黄緑と空色、丸い手書き風文字
- 音：のんびりウクレレ系BGM、「ぽよん」「ブブー」「ピンポーン」効果音

## B「けむしクイズ王けってい戦！」
- 仕掛け：テレビのクイズ番組。「けむしを見つけた！どうする？」の○✕クイズで「けむし博士」をめざす
- 形：大きな文字とカラフルな画面が音楽に合わせて切りかわる
- 流れ：オープニング → Q「ちょっとだけならさわっていい？」✕ → Q「ぼうでつつく？」✕ → Q「おとなに言う？」○ → Q「さわっちゃった！こする？」✕ → 博士認定証 → 合言葉
- 見た目：ポップでビビッド、太い文字
- 音：アップテンポ、正解・不正解の効果音

## C（チャレンジ案）「ぼく、けむしのモジャ」
- 仕掛け：毛虫本人がナレーター。「ぼくの毛はね、身を守るためにあるんだ。だから、さわらないでね」
- 形：葉っぱからどんどんズームしていく
- 流れ：自己紹介 → なぜ毛があるの？ → 見つけたらどうしてほしい？（さわらない・おとなに言う）→ さなぎ → ガになって飛んでいく
- 見た目：水彩風、やさしい色
- 音：ピアノとオルゴール
