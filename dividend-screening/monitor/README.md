# 高配当ウォッチ（自動監視）

毎週土曜 9:37 JST にスケジュールタスクが自動で実行されます（金曜終値で判定）。

## 毎回の処理
1. `watchlist.csv` の銘柄について、当日の株価・配当予想の変更・業績修正をWeb検索で集め、`prices.json` に書き出す
2. `python3 check.py prices.json` で判定する
3. 判定が上がったとき（🟡接近 / 🟢買い目安・強い買い）、配当予想が変わったとき（⚠️）、翌週に決算などのイベントがある銘柄のうち接近以上のものを、スマホに通知する
4. `reports/日付.md` と `state.json` をコミットして保存する

## 判定の基準（予想配当 ÷ 株価）
| 判定 | 条件 |
|---|---|
| 強い買い | 利回り4.5%以上 |
| 買い目安 | 利回り4%以上 |
| 接近 | 4%になる株価まであと3%以内 |
| 待機 | それ以外 |

- 配当は普通配当で計算します。リコーリースの特別配当70円は含めません。
- 配当予想が変わったとき、決算が下方修正されたとき、減配があったときは ⚠️ で通知します。

## 銘柄の分類
- **core**：詳しく調べた結果、配当が堅いと判断した13社
- **wait**：今は4%に届かず、値下がりを待つ銘柄

## 保有銘柄（非公開）
- このリポジトリは公開されているため、株数・取得単価・口座は**リポジトリに置きません**。
- 保有情報は、スケジュールタスクの指示文の中だけに持たせています。実行のたびに、その場で `holdings.csv` を作ります（.gitignore 済み）。
- 保有銘柄の評価額と受取配当は `reports/private_<日付>.md` に出します（これもコミットしません）。内容はスマホ通知でだけ伝えます。
- 保有している銘柄で、減配・業績の下方修正・配当予想の変更があったときは ⚠️ で通知します。

## 編集のしかた
- 銘柄を追加・削除する：`watchlist.csv` を編集します
- 配当予想を更新する：`dps` 列を書き換えます

## 制約
- この環境からは株価APIや証券サイトに直接アクセスできません。株価は検索結果から取るため、数分〜1日遅れたり、取れない日があったりします。
- 取れなかった銘柄はレポートに「取得失敗」と表示されます。
- 投資助言ではありません。
