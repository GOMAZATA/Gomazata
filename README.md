# Gomazata — 未経験からアプリを出すまでのロードマップ

プログラミング未経験から、Claude Code を相棒にしてスマホアプリを公開するまでの道のり。
動画では「7ステップ」と紹介されているけど、カードは **8ステップ + 宝（公開後）** の全9枚。

| # | やること | 目安 | 使うもの / 学ぶもの |
|---|---|---|---|
| 1 | Claude Code で **ローカルで動く Web ツール** を作る | 3日 | Claude Code（日本語で頼むと AI が作る）、ローカル（まだ自分だけが使える） |
| 2 | それを **ネットに公開**。データの保存と公開の流れを一周 | 1週間 | Supabase（データの保管庫）、Vercel（ネットに出す置き場） |
| 3 | **守り方・設計・運用・自動化** を学ぶ | 1.5か月 | セキュリティ・データ設計、Git・CI/CD（変更の記録と公開の自動化） |
| 4 | Claude Code と Expo で **スマホアプリの開発手法** を学ぶ | 3週間 | Expo（iPhone と Android 両方に出せる）、Apple 開発者登録（年99ドル） |
| 5 | **審査のルールと規約**、法律の基本も押さえる | 1週間 | 審査ガイドライン（Apple が通す条件）、プライバシーポリシー |
| 6 | お金をかけずに SNS を運用して **最初の1000人** を集める設計 | 2週間 | TikTok・Threads（広告費0円で発信）、毎日出す形を決める |
| 7 | Claude Code で **モック** を作って需要を確かめる | 1週間 | モック（画面だけのハリボテ）を作って反応を見る |
| 8 | Claude Code と Codex で **自分のアプリを制作** | 4週間 | Claude Code で作る、Codex（もう1体の AI）と分担 |
| 宝 | 公開後、**ユーザーの声を反映してアップデート** | 30日 | レビュー・問い合わせ → 直して出し直す |

合計の目安：およそ 4〜5か月。

## 各ステップの「ゴール」と Claude Code への頼み方

### 1. ローカルで動く Web ツール（3日）
- **ゴール**：自分の PC のブラウザで動く小さな道具を1つ完成させる。
- **頼み方の例**：「毎日の支出をメモして合計を出す Web ページを、HTML 1ファイルで作って。データはブラウザに保存して」
- ✅ このリポジトリの [`step1-roadmap-tracker/`](step1-roadmap-tracker/) がその見本（このロードマップの進捗チェッカー）。

### 2. ネットに公開（1週間）
- **ゴール**：ステップ1のツールを URL で誰でも開ける状態にし、データをサーバー側に保存する。
- 流れ：GitHub にコードを置く → Vercel につないで公開 → Supabase にテーブルを作って保存先を切り替える。
- **頼み方の例**：「このツールの保存先を localStorage から Supabase に変えて。手順も教えて」

### 3. 守り方・設計・運用・自動化（1.5か月）
- **ゴール**：「動く」から「安心して使ってもらえる」へ。
- 押さえること：API キーをコードに直書きしない／Supabase の RLS（行ごとのアクセス制限）／テーブル設計／Git でこまめにコミット／GitHub Actions で自動テスト・自動デプロイ。
- **頼み方の例**：「このアプリのセキュリティ上の問題点をレビューして、直し方を教えて」

### 4. Expo でスマホアプリ（3週間）
- **ゴール**：手元のスマホ（Expo Go）で自作アプリが動く。
- Apple Developer Program（年99ドル）の登録は手続きに日数がかかることがあるので早めに。
- **頼み方の例**：「Expo でステップ2と同じ機能のスマホアプリを作って」

### 5. 審査と規約（1週間）
- **ゴール**：審査で落ちない準備。
- App Store 審査ガイドラインを読む／プライバシーポリシーと利用規約を用意（集めるデータを正直に書く）／アカウント削除機能など必須要件の確認。

### 6. SNS で最初の1000人（2週間）
- **ゴール**：広告費0円で、毎日発信できる「型」を決める。
- 開発の過程そのものをネタにする（作ってる様子・失敗談・数字）。

### 7. モックで需要確認（1週間）
- **ゴール**：本格的に作る前に「欲しい」と言ってくれる人がいるか確かめる。
- 画面だけのハリボテを Claude Code で作り、SNS で見せて反応（いいね・コメント・事前登録）を測る。

### 8. 自分のアプリを制作（4週間）
- **ゴール**：需要が確認できたアイデアを本番品質で作り、ストアに申請する。
- Claude Code と Codex で役割分担（例：片方が実装、もう片方がレビューやテスト）。

### 宝. 公開後のアップデート（30日〜）
- **ゴール**：レビュー・問い合わせを集めて、直して、出し直すサイクルを回す。
